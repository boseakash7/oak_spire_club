================================================================================
                    OAK SPIRE CLUB - FCM TOPICS REFERENCE
================================================================================

All Firebase Cloud Messaging (FCM) topics used in the application follow the 
prefix: `oakspire_`

--------------------------------------------------------------------------------
1. REGISTRATION STATE TOPICS
--------------------------------------------------------------------------------
• oakspire_unregistered_users
  - Assigned on: Fresh app launch / unauthenticated state (`user == null`).
  - Target: Users who have not yet created an account or signed in.

• oakspire_registered_users
  - Assigned ONLY on: New User Sign-Up / Registration (`SignUpController.onRegister()`).
  - NOTE: NOT assigned on login! Used specifically for welcoming brand-new registrants.

• oakspire_topic_logout
  - Assigned on: Explicit User Logout or Account Deletion.
  - Target: Devices where a user has logged out. (All other topics are unsubscribed).


--------------------------------------------------------------------------------
2. USER SUBSCRIPTION TIER TOPICS
--------------------------------------------------------------------------------
• oakspire_free_user
  - Assigned on: Home page evaluation when `user.isFreeUser == true`.
  - Target: Users granted free premium access directly from backend without payment.

• oakspire_paid_user
  - Assigned on: Home page evaluation when `user.hasActiveSubscription == true`.
  - Target: Members with an active paid subscription plan.

• oakspire_trial_user
  - Assigned on: Home page evaluation when user is non-premium / trial user.
  - Target: Standard members / trial users who do not have paid or free premium access.


--------------------------------------------------------------------------------
3. ALERT NOTIFICATION PREFERENCE TOPICS
--------------------------------------------------------------------------------
• oakspire_collection
  - Managed by: User Notification Preference toggle "Collection Value".

• oakspire_market
  - Managed by: User Notification Preference toggle "Market Benchmarks".

• oakspire_price_movement
  - Managed by: User Notification Preference toggle "Price Movement".

• oakspire_tips
  - Managed by: User Notification Preference toggle "Tips & Product Updates".


--------------------------------------------------------------------------------
4. SENDING (ADMIN PANEL > NOTIFICATIONS, oakspireweb)
--------------------------------------------------------------------------------
Each message has an audience and a topic, combined into one FCM condition, so
a device gets it once:

  topic && (audience topic || audience topic ...)

Audiences (state topics):
  Everyone ............... free_user, paid_user, trial_user, unregistered_users, topic_logout
  All members ............ free_user, paid_user, trial_user
  Premium members ........ free_user, paid_user
  Paid subscribers ....... paid_user
  Free premium members ... free_user
  Members without premium  trial_user
  New sign-ups ........... registered_users
  Guests ................. unregistered_users
  Signed-out devices ..... topic_logout   (only with "Account notice")

Topics (alert preference topics): tips, market, price_movement, collection,
or "Account notice", which sends whatever the user's toggles say.

Tap data: `screen` = home | market | collection | subscription (or empty),
opened by NotificationTapRouter.

Keep this file, FirebaseNotificationTopics (app) and Firebase::AUDIENCES /
CATEGORIES (oakspireweb) in step.

================================================================================
